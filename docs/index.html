対応できること

データ収集・整形
Web サイトや API のデータを定期取得し、CSV やスプレッドシートにまとめます。取得元の利用規約とアクセス頻度を確認します。
集計・転記・帳票の自動化
Google Apps Script や Excel VBA で、繰り返し行う表計算の作業を自動化します。
監視・通知
在庫、サイトの更新や応答時間、サーバーの状態を確認し、変化や点検結果を Slack・LINE・メールで通知します。
業務ツールの開発
決まった手順で行う判定や集計をツール化します。必要に応じて AI による要約や分類も組み込みます。

開発事例

自分の業務用に開発し、運用しているツールです。

  • 日次データの変化を Slack に通知

    株価などの数値データから条件に合う変化を検出し、Windows サーバーから毎日通知しています。

    Python・データベース・Slack

  • 公開情報の収集と朝のレポート

    収集した候補をルールと AI で絞り込み、毎朝レポートを作成。元データを保存し、条件変更時に再集計できます。

    Python・SQLite・Claude API・Slack

  • 複数の公開データから指数を毎日更新

    種類の異なる公開データを過去の分布に基づいて 0〜100 にそろえ、ひとつの指数として Web ページに公開しています。

    Python・静的サイト・VPS

  • サーバーの日次点検

    毎日の点検結果を Slack に通知し、点検スクリプトと fail2ban などの設定を Ansible で管理しています。

    シェルスクリプト・Ansible・fail2ban
